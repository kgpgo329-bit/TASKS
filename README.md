# 🌿 منصة مهامي (Waqar & Injaz) - MVP قابل للإنتاج والنشر

نظام إداري ودعوي متكامل لإدارة ومتابعة المهام التشغيلية والدعوية لجمعية إرشاد الجاليات، مع نظام تسجيل دخول موحد وصلاحيات دقيقة تعزل بيانات **الموظفة** عن **المديرة**، مدعوماً بقاعدة بيانات **Supabase** وحماية **Row Level Security (RLS)**، وجاهز للنشر المباشر على **Vercel** وحفظه في **GitHub**.

---

## 🌟 الميزات المنفذة في هذا الإصدار (MVP)

### 1. نظام الدخول الموحد (Unified Authentication)
* رابط تسجيل دخول موحد للجميع (`/login`).
* التحقق من حالة الحساب: إذا كان الحساب **معطلاً** يتم رفض الدخول فوراً مع إشعار للمستخدم.
* توجيه ذكي حسب الدور فور تسجيل الدخول:
  - **الموظفة**: تُوجّه مباشرة إلى شاشة "مهامي الخاصة بي" (`/my-tasks`).
  - **المديرة**: تُوجّه إلى "لوحة التحكم العامة" (`/dashboard`).

### 2. صلاحيات الموظفة (Employee)
* **عزل كامل للبيانات**: لا ترى الموظفة إلا المهام الخاصة بحسابها فقط (مطبقة عبر سياسات RLS على مستوى قاعدة البيانات وليس واجهة فقط).
* إضافة مهام جديدة لنفسها وتعديلها وحذفها.
* تغيير حالة المهام بحرية:
  - ⚪ **لم يتم** (`not_started`)
  - 🟡 **قيد التنفيذ** (`in_progress`)
  - 🟢 **تم الإنجاز** (`completed`)
* تصدير مهامها إلى Excel/CSV وطباعتها.
* خيار "إدارة الموظفات" مخفي تماماً من القائمة الجانبية.
* **حماية المسارات**: محاولة الدخول إلى صفحات المديرة (`/employees` أو `/dashboard` أو `/all-tasks`) مباشرة عبر الرابط تُحجب فوراً وتُعاد إلى مهامها.

### 3. صلاحيات المديرة (Manager)
* **لوحة التحكم والمؤشرات (Dashboard)**:
  - استعراض إجمالي مهام الجمعية، نسب الإنجاز، وفريق العمل.
  - متابعة المهام العاجلة والحرجة لليوم لكافة الموظفات.
* **شاشة جميع المهام (All Tasks)**:
  - استعراض كافة مهام الموظفات مع إبراز اسم الموظفة المكلفة على كل بطاقة مهمة.
  - تصفية المهام حسب الموظفة، الحالة، أو الأولوية.
  - إمكانية إضافة مهمة جديدة وتكليف أي موظفة بها.
  - تصدير تقرير مهام الجمعية بالكامل كـ Excel/CSV.
* **صفحة إدارة الموظفات (Employees Management)**:
  - زر **"إضافة موظفة جديدة"**: (الاسم، البريد الإلكتروني، كلمة مرور مؤقتة، الدور: موظفة / مديرة، حالة الحساب).
  - بعد إنشاء الحساب، تستطيع الموظفة تسجيل الدخول فوراً من نفس الرابط.
  - تعديل بيانات الموظفة وتغيير دورها.
  - تعطيل / تفعيل حساب أي موظفة بضغطة زر.
  - حذف حساب الموظفة نهائياً.

### 4. أمان البيانات والـ API (Security First)
* **Row Level Security (RLS)** مفعل على جداول `profiles` و `tasks`.
* مسارات الخادم الإدارية (`/api/admin/users`) آمنة تماماً وتتحقق من الـ JWT الخاص بالمديرة.
* مفتاح الخادم السري (`SUPABASE_SERVICE_ROLE_KEY`) غير معرّض للفرونت إند إطلاقاً.

## 🚀 دليل التشغيل والإعداد السريع

### الخطوة 1: إعداد قاعدة بيانات Supabase
1. أنشئي مشروعاً جديداً على [Supabase](https://supabase.com).
2. من القائمة الجانبية في Supabase، افتحي **SQL Editor**.
3. انسخي كامل محتويات الملف [`supabase/schema.sql`](./supabase/schema.sql) والصقيها في المحرر ثم اضغطي **Run**.
4. سيتم إنشاء الجداول، الفهارس، التريجرز، وسياسات الـ RLS بنجاح.

### الخطوة 2: إنشاء حساب المديرة الأولى
لإنشاء حساب المديرة الرئيسي:
1. في لوحة Supabase، اذهبي إلى **Authentication > Users** واضغطي **Add user > Create user**.
2. أدخلي البريد الإلكتروني (مثلاً: `manager@mahamee.local`) وكلمة المرور.
3. افتحي **SQL Editor** ونفذي الاستعلام التالي لمنح الحساب صلاحيات المديرة:
```sql
update public.profiles
set role = 'manager', is_active = true
where email = 'manager@mahamee.local';
```
4. الآن أصبح هذا الحساب مديراً للنظام!

### الخطوة 3: إعداد المتغيرات البيئية (.env.local)
من لوحة Supabase: اذهبي إلى **Project Settings > API** وانسخي القيم التالية إلى ملف `.env.local` في مجلد المشروع:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## 🌐 دليل النشر على Vercel و GitHub

### 1. الرفع إلى GitHub
المشروع مهيأ مسبقاً بمستودع Git:
```bash
git add .
git commit -m "إطلاق MVP تطبيق مهامي مع تسجيل الدخول وصلاحيات الموظفة والمديرة"
git branch -M main
git remote add origin https://github.com/USERNAME/mahamee.git
git push -u origin main
```

### 2. النشر على Vercel
1. سجلي الدخول إلى [Vercel](https://vercel.com).
2. اضغطي **Add New > Project**.
3. اختاري مستودع `mahamee` من حسابك في GitHub.
4. في قسم **Environment Variables**، أضيفي المتغيرات الثلاثة:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
5. اضغطي **Deploy**.
6. في غضون دقيقة واحدة سيكون موقعكِ متاحاً على الإنترنت برابط رسمي ومجاني!
